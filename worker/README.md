# Local review and brief API

This Cloudflare Worker and its D1 schema support the demo's local review, practice reports and brief workflows. The root run instructions start this Worker locally alongside the web app. The rebuild's official data intake and training run in offline Python batches. Public UI integration uses synthetic demo artifacts or explicitly reviewed aggregates.

See [the local run guide](../README.md) and [the model plan](../docs/MODEL_PLAN.md).
