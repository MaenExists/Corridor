# Offline map data

- `kerala-districts.geojson`: simplified district geometry adapted from © OpenStreetMap contributors via [Open Data Kerala](https://github.com/opendatakerala/kl_district), taken from the owner's companion workspace. The adapted database is provided under [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/); see [OpenStreetMap attribution](https://www.openstreetmap.org/copyright). Boundaries are illustrative, not legal.
- `places.json`: selected locality rows from the [GeoNames India country dump](https://download.geonames.org/export/dump/IN.zip), via the companion workspace; [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Modified to retain a sampling of populated places with name, alternate names, district, location and source reference. Geography only, not case or movement evidence.
- No online tiles or geocoding are requested. Credits link to the providers if a visitor chooses to open them.
