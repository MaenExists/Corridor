# Kerala map sources

These layers provide geographic context for the synthetic demonstration and planned district summaries. Service listings and case evidence have separate sources.

- `kerala-districts.geojson`: simplified district geometry adapted from © OpenStreetMap contributors via [Open Data Kerala](https://github.com/opendatakerala/kl_district), taken from the owner's companion workspace. The adapted database is provided under [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/); see [OpenStreetMap attribution](https://www.openstreetmap.org/copyright). Boundaries are illustrative, not legal.
- `places.json`: selected locality rows from the [GeoNames India country dump](https://download.geonames.org/export/dump/IN.zip), via the companion workspace; [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Modified to retain a sampling of populated places with name, alternate names, district, location and source reference. Geography only, not case or movement evidence.
- `kerala-places.json`: the companion workspace's enriched GeoNames catalogue, including populated places, district profiles and public transport reference points; [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The local snapshot retains its source metadata and links. Points are not a verified service inventory and never count as movement evidence.
- `kerala-state.geojson`: the companion workspace's simplified Kerala state outline, adapted from [OpenStreetMap relation 2018151](https://www.openstreetmap.org/relation/2018151), [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). `land.geojson` uses the companion workspace's simplified Natural Earth land context, [public domain](https://www.naturalearthdata.com/about/terms-of-use/).
- `kerala-satellite.webp`: color-graded regional composite of [NASA EOSDIS GIBS](https://nasa-gibs.github.io/gibs-api-docs/) Blue Marble shaded relief/bathymetry and Landsat/WELD annual true color for `2000-12-01`. The public map request covers 68.0–83.2° E, 6.3–15.1° N in EPSG:3857. `scripts/prepare-basemap.py` reproduces it from two fixed public map requests. This is archival imagery, not live surveillance or case evidence.
- The synthetic workspace defaults to [OpenStreetMap standard raster tiles](https://operations.osmfoundation.org/policies/tiles/), with a bundled satellite archive fallback. Optional [NASA GIBS](https://nasa-gibs.github.io/gibs-api-docs/) detail tiles are available in Layers. District boundaries and place search work offline. Tile requests use geographic tile coordinates; searches, case features and review storage stay local. The private aggregate view does not load a basemap.
