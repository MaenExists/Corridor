# Kerala data sources and bulk acquisition

Reviewed 24 November 2026. Public portal access and catalog evidence are distinguished from release coverage and from permission for bulk ML use. The local acquisition checkpoint is recorded in the Git-ignored file `docs/progress/PUBLIC_COLLECTION.md`. It includes published official tables, a public care directory and a local court document candidate archive.

## 2. Courts and independent evidence at scale

| Source | Bulk strategy and limitations |
| --- | --- |
| **Dattam Labs Indian High Court Judgments on AWS Open Data** | Best keyless bulk legal lead. The documented public S3 bucket offers structured Parquet metadata, individual PDFs and tar archives under CC BY 4.0. Kerala is court code **32_4**, bench **highcourtofkerala**. HTTP HEAD succeeded for all seven 2020–2026 Parquet objects. The older objects range from roughly 20–37 MB, while 2025 is 2.74 MB and 2026 about 62 KB. Verify decision date ranges and case counts before assuming coverage. Start with metadata partitions and a small PDF sample. [Registry](https://registry.opendata.aws/indian-high-court-judgments/) · [Partition layout](https://github.com/vanga/indian-high-court-judgments/blob/main/opendata/docs/dataset.md) · [Court mapping](https://github.com/vanga/indian-high-court-judgments/blob/main/opendata/docs/high_courts.csv) |
| **Official eCourts Judgments & Orders** | Search by court, act, keywords and date for spot checks. The official search uses a CAPTCHA. For wider lower-court coverage, ask the Kerala High Court Registry/eCourts administrators about a public or approved research extract for Sessions/Special NDPS courts. Public search is a comparison sample. [Official judgments portal](https://judgments.ecourts.gov.in/pdfsearch/index.php) |
| **Indian Kanoon API** | Targeted gap-fill via searches filtered to Kerala High Court and published date windows. The documented API has paginated search, original documents and metadata. Requires an account and token or signed requests. Confirm training, retention and redistribution terms in writing and estimate cost from the published menu before bulk purchase. Search substantially smaller month or quarter windows only as needed to avoid capped result sets. [API docs](https://api.indiankanoon.org/documentation/) · [Pricing](https://api.indiankanoon.org/pricing/) · [Terms](https://api.indiankanoon.org/terms/) |
| **eCourtsIndia commercial service** | The separate provider has a public Kerala FIR catalog and an authenticated court API. Its own year table is highly uneven. Ask for a Kerala NDPS-only sample and written confirmation of a searchable FIR export, years/districts, revision provenance and permitted training use before procurement. Treat the catalog as selected. [FIR catalog and year coverage](https://ecourtsindia.com/CrimeReports/Kerala) · [API guide](https://mcp.ecourtsindia.com/guides/court-data-api-india/) |
| **Publisher archives** | Pilot Onmanorama and Mathrubhumi, with additional Malayalam and English publishers if access is granted. Start with publisher maps and date archives, or ask for a licensed subject/date metadata feed. Search NDPS, narcotics seizure, ganja, MDMA, drug seizure, ലഹരിമരുന്ന്, കഞ്ചാവ്, എംഡിഎംഎ and പിടികൂടി with normalized district terms. Check terms and permissions before automation, caching or text retention. Link syndicated accounts to one incident. [Onmanorama site map](https://www.onmanorama.com/content-map.html) · [Mathrubhumi archive](https://sv1.mathrubhumi.com/online/malayalam/news/archives/) |
| **GDELT GKG and Common Crawl** | For 2020–2026, use date-partitioned GDELT GKG in BigQuery or the downloadable feed as a publisher/domain and location index. Run a dry run with a bytes cap before BigQuery billing. GKG is discovery metadata. For dead publisher URLs or complementary discovery, use Common Crawl's CDX for targeted known URLs, or columnar index for bulk filtering by domain/date. Public indexes have no API key requirement. Audit Malayalam recall and original timestamps. Archive access doesn't grant publisher training rights. [GDELT data access](https://www.gdeltproject.org/data.html) · [GDELT partitioned tables](https://blog.gdeltproject.org/announcing-partitioned-gdelt-bigquery-tables/) · [Common Crawl index guidance](https://index.commoncrawl.org/) |
| **Indiastat / secondary statistical compilers** | Useful inventory for locating older official tables. Prefer original government publications and avoid purchasing reprinted equivalents. [Indiastat Kerala catalog](https://www.indiastatdistrictagri.com/kerala/all-districts/crimeandlaw/drugsnarcotics/data-year/2025) |

For the first approved court intake, use anonymous HTTPS or AWS CLI unsigned access to list only the Kerala partition. Start with 2024 metadata. The public path has the form **metadata/parquet/year=2024/court=32_4/bench=highcourtofkerala/metadata.parquet**. Use local DuckDB or PyArrow to project the fields needed for date and case-type counts. The date partitions represent decision years. Retrieve selected PDFs using the metadata pointer or tar index. Orders on one docket and repeated docket references can describe the same incident. Count the underlying event once per target definition and retain its earliest defensible release vintage. Court disposition, agency account, allegation, mention of other cases and evidence status need separate extraction labels. A bail order alone is evidence of a proceeding.

Pilot about **100 documents** total, with court and media, both languages as available, early and late years, varied districts and negative examples. Double-review an overlapping sample. Report precision and recall for event/date/district, inter-rater disagreement, explicit endpoint yield, duplicate rate, and availability gaps by year and district. Scale one source at a time against a frozen review set. Use a resumable manifest per source, month and partition with counts, hashes, timing and disposition. Cache authorized files locally with source-specific limits. Hold out duplicate clusters across extraction evaluation splits. Use CPU OCR for image-only pages. Raw text, document links, case identifiers, and location details remain local.

### Publisher sitemaps used for the grid forecast (acquired 25–26 November 2026)

`make news-harvest` reads only sitemaps that each publisher's robots.txt advertises to crawlers. Sources and depth:

- **New Indian Express** daily sitemaps from 2016. The Kerala, Kochi and Thiruvananthapuram sections are used.
- **Times of India** monthly city sitemaps from 2016: Kochi, Thiruvananthapuram and Kozhikode.
- **Asianet News** daily sitemaps from January 2022, its earliest: the Kerala and local-news sections.
- **Onmanorama**'s rolling sitemaps of recent weeks.

The Hindu's robots.txt disallows its archive sitemaps, so it is not used. Manorama Online and Mathrubhumi disallow crawling of their sites and are not used. For each headline-selected candidate, only the publisher's own meta description is fetched. Article text is not retrieved. Sitemaps, summaries and the incident table stay local and gitignored. The result is a selected sample of *reported* seizures, dominated by city desks.

## 3. Public recovery and service planning

| Source | Acquisition and use |
| --- | --- |
| **Excise Mayangilla Keralam / Vimukthi** | The official directory lists 14 centres across 14 districts. Use it for public listings, verify service, hours and contact details, and store verification dates. Ask Vimukthi and its hospital partners for aggregate monthly service and capacity extracts. [Official centres](https://mayangillakeralam.kerala.gov.in/de-addiction-centres) · [State annual plan programme](https://spb.kerala.gov.in/sites/default/files/inline-files/Annual%20Plan%202023-24.pdf) |
| **Kerala DHS, NHM/DMHP and Kerala State Mental Health Authority** | Use official hospital and registered establishment directories to verify licensed services. Ask the DHS/NHM data custodian whether HMIS or programme returns contain applicable de-addiction indicators and through which reporting period. Request district-month aggregates or provider-approved summaries, with a data dictionary. [DHS hospitals](https://dhs.kerala.gov.in/en/dhsw/) · [KSMHA registers](https://www.ksmha.org/Regofmentalhealthes.html) · [Kerala HMIS description](https://health.kerala.gov.in/assets/backend/publications/Health%40Ernakulam.pdf) |
| **MoSJE / National Drug Dependence Treatment Centre at AIIMS** | 2019 Magnitude of Substance Use in India is a survey baseline outside the training period. A 2026 government update describes a commissioned second survey with intended district estimates. Verify release and data rights before using further results. MoSJE programme centres can supplement the directory after verification. [2019 survey](https://socialjustice.gov.in/writereaddata/UploadFile/Magnitude_Substance_Use_India_REPORT.pdf) · [2026 programme update](https://www.pib.gov.in/PressReleasePage.aspx?PRID=2237623&lang=1&reg=3) |

Recovery access map inputs: the [State Mental Health Authority register of de-addiction centres](https://www.ksmha.org/Documents/Registered%20MHE.pdf) (70 pages, beds and PIN codes), the [WorldPop 2020 1 km India population grid](https://hub.worldpop.org/geodata/summary?id=31799) (CC BY 4.0), the [GeoNames India postal codes](https://download.geonames.org/export/zip/) (CC BY 4.0), and the OpenStreetMap Nominatim geocoder for five town names. No public source reports treatment demand below state level. Wastewater surveillance would be the anonymous, near-real-time option for measuring use by catchment, though septic systems limit its coverage in Kerala.

Treatment visits measure use of available services. Estimates of people affected require a representative survey, compatible definitions and uncertainty. Do not substitute seizures, treatment counts or citizen allegations for prevalence. For health planning compare wait times, staffed capacity and recorded demand with coverage, and show a separate unknown state.
