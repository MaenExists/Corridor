# Hackfinity demo

Run **make serve** with a prepared snapshot, then open **http://127.0.0.1:5173/?offline=1**. To build the snapshot from scratch, use **make setup && make demo**.

1. Introduce Corridor as a student project for forecasting recorded seizure activity and improving access to care in Kerala. Present the demo with the synthetic badge visible.
2. Open **Challenge**, select an earlier origin, run the frozen district model, then reveal the outcome in the synthetic archive. Show the forecast range, the observed count and the baseline result.
3. Open **Forecasts** and **Model evidence**. Show a district with an abstention, then find a case where a simple method did better. Explain that official coverage and reporting effort determine when a real forecast can issue.
4. Show the official recovery directory as the source for a public service finder. Explain how care teams would use separately approved aggregate waiting times, demand and staffed capacity. [Official centre directory](https://mayangillakeralam.kerala.gov.in/de-addiction-centres)
5. Show the two asks on the final slide or in discussion. The district counts and release timing from Police and Excise enable the real count forecast. Monthly care aggregates enable demand and capacity planning. [Data requests](DATA_REQUESTS.md)

The replay is a demonstration of the forecasting and evaluation process. A real-world forecast needs authorized data and a later evaluation. Any synthetic source, review note, priority marker or brief stays labelled synthetic. Keep the optional local analyst workflow in reserve for questions.
