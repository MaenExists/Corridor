# Corridor — five-minute public demo

Start `make demo` early. Open **http://127.0.0.1:5173** and have the local review key handy. Stay on **Synthetic (demo)** for the public presentation. The real aggregate is not bundled; use it only in a private, owner-reviewed session.

Say these three sentences first:

1. “This is a team proposal, and we're demonstrating it with synthetic data.”
2. “The system estimates documented cases, not all drug movement or whether an interception would succeed.”
3. “Any operational use would first require an agency-led evaluation on authorized data and later independent outcomes.”

| Time | Show and say |
|---|---|
| 0:30 | On the atlas, select Ernakulam, 28 days. Show the predicted count, its range and the information cutoff. Switch to Wayanad: “Unknown coverage is not safety. Here the system abstains.” |
| 1:20 | Toggle History, Documented connections and Infrastructure hypotheses. Say the connections are invented, district-scale sketches. A possible transport link is not movement evidence. |
| 2:00 | Open News inbox. Point out the possible duplicate. Verify a non-duplicate fictional fixture; run `make refresh`, click **Reload forecasts**, and show its review time. Say this does not prove the cue improves the model. |
| 3:00 | Open Model report and play the held-out replay. Compare 28-day results with a simple forecast, then show district losses and the 7-day method comparison. Say the synthetic ranges contained only about 68–72% against an 80% target. |
| 4:00 | Open Data & coverage and explain the feedback loop: attention can create more documented cases, not necessarily more underlying activity. Return to the atlas, **Start a brief**, save and export. Nothing is sent to any agency. |

If the inbox has already been reviewed, show the existing review history and its timestamp. If the replay controls are unavailable, open the local synthetic HTML report. Do not substitute a real case story or claim an agency partnership.
